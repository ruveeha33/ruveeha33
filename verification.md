## Reproduce

Download [reproduce-nuclearshield.py](reproduce-nuclearshield.py) and [nuclearshield-requirements-lock.txt](nuclearshield-requirements-lock.txt) into a clean working directory.

```bash
git clone https://github.com/ruveeha33/NuclearShield.git
git -C NuclearShield checkout a7f23e00236fac199bc928accc7734f0a59975c9
python3 -m venv venv
venv/bin/pip install -r nuclearshield-requirements-lock.txt
(cd NuclearShield && ../venv/bin/python -m pytest -q --junitxml=../tests.xml)
venv/bin/python reproduce-nuclearshield.py NuclearShield output
```

The driver uses an isolated temporary data directory and bundled synthetic inputs. It exports actual API analysis JSON and an HTML report. Its generated analysis identifiers and timestamps may differ on another run.
